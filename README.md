# Tsuki Musings 🌙

> 一位喜欢思考各种问题的幼稚小孩子，把思考的过程中整理了下来 >w<

## 这是什么

这里记录的是在日常生活中碰到的各种思考——心理学、哲学、社会观察、还有一些说不清归到哪类的问题。

它不是答案，是我提出的问题。
它不是结论，是我思考的过程。

**不是“我想通了”，是“我还在想”。**

## 为什么叫这个

**Tsuki** 是我的名字。
**Musings** 是“随想、漫谈”——本身就带“不成体系、随性”的含义。

合在一起，就是一个还在想的人，随手记下的东西。

## 这里会有什么

| 方向 | 大概是什么 |
|---|---|
| **心理学** | 情绪、关系、自我认知、原生家庭、亲密关系 |
| **哲学** | 宿命、自由、选择、时间、意义 |
| **社会观察** | 阶级、信息茧房、职场、用工制度 |
| **日常思考** | 那些突然冒出来、但不写下来就会忘的问题 |

## 我的态度

**幼稚是真的，诚实也是真的。**

我不打算假装自己已经想通了一切。很多问题，我只有一半的答案，甚至只有问题本身。但我觉得，把“想的过程”写出来，比只放“想好的结论”更有价值。

如果你看到某篇觉得“这也太幼稚了”——你说得对，它本来就是。但我相信，一个人愿意把不成熟的想法写下来，比一个人只展示成熟结论，更接近真实。

## 怎么读

- **随便翻**：不用按顺序，哪篇标题顺眼点哪篇
- **带着怀疑读**：我不保证对，我只保证诚实
- **如果不同意**：欢迎开 issue 或者直接跟我说，我想听不一样的观点
